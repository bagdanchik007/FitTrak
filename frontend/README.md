# FitTrack Frontend

React + TypeScript + Vite + Tailwind CSS client for the FitTrack API.

## Setup

```bash
cd frontend
npm install
npm run dev
```

Dev server: http://localhost:5173  
API proxy: `/api` → `http://localhost:8000`

## Screens

- Home, Login, Register
- Dashboard (stats + streak)
- Workouts list

JWT access/refresh tokens are stored in `localStorage`.
